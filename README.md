\# Bookstore REST API



\## About the Project



This project is a Python-based Bookstore REST API practical that demonstrates how to communicate with an API and perform CRUD (Create, Read, Update, Delete) operations.



The project uses MockAPI as a simulated backend to manage bookstore inventory.



\## Features



\- \*\*GET:\*\* Retrieve all books from the API.

\- \*\*POST:\*\* Add a new book.

\- \*\*PUT:\*\* Update an existing book.

\- \*\*DELETE:\*\* Remove a book.

\- \*\*Error Handling:\*\* Handle HTTP errors and check whether a deleted book still exists.
